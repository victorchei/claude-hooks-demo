# claude-hooks-demo

Навчальний репозиторій до доповіді «Claude Code: Хуки». Шість робочих
прикладів хуків, які можна побачити наживо за кілька хвилин. Працює на
macOS, Windows і Linux; розробницький досвід не потрібен.

**Хук** — це маленька програма, яку Claude Code запускає сам на певну подію:
на старті сесії, до або після запису файлу чи виконання команди, коли Claude
чекає на вас. Тут кожен хук показує результат рядком у терміналі й системним
звуком.

## Швидкий старт (3 кроки)

1. Встановіть [Claude Code](https://code.claude.com/docs/en/setup) і
   [Node.js 18+](https://nodejs.org) (Node — «двигун» хуків; якщо його немає,
   Claude сам підкаже, як поставити).
2. Скачайте репозиторій і запустіть `claude` **з його кореня**, підтвердивши
   довіру до теки й проєктних хуків:
   ```bash
   git clone https://github.com/victorchei/claude-hooks-demo
   cd claude-hooks-demo
   claude
   ```
3. Напишіть `/demo` — Claude проведе вас через усі шість хуків крок за кроком.
   Або йдіть за кроками нижче вручну.

Решту залежностей (`git`, за бажанням `gh`) на старті доставить хук
`SessionStart` сам: побачите `✓ Node … + усі залежності вже встановлено` або
`⚠ Бракувало: … — запущено install.mjs`.

## Структура

```
claude-hooks-demo/
├── .claude/
│   ├── settings.json                  # реєструє всі шість хуків
│   └── commands/demo.md               # команда /demo — інтерактивний показ
├── hooks/
│   ├── session_start_deps.mjs         # SessionStart — перевіряє й доставляє залежності
│   ├── format_on_write.mjs            # PostToolUse — автоформат після Edit/Write
│   ├── protect_env.mjs                # PreToolUse — блокує правки .env
│   ├── block_direct_master_commit.mjs # PreToolUse — блокує прямий коміт у master/main
│   ├── notify_pr_created.mjs          # PostToolUse — push-сповіщення при створенні PR
│   ├── notify_mobile.mjs              # Notification — дублює сповіщення Claude на телефон
│   └── lib.mjs                        # спільне: рядок у термінал, звук, ntfy
├── scripts/preflight.mjs              # перевірка готовності перед показом
├── src/app.js                         # файл для експериментів
├── install.mjs                        # ручне встановлення залежностей
├── CLAUDE.md                          # інструкція Claude для режиму показу
├── secrets.example
└── README.md
```

## Перед показом (чекліст)

Запустіть `node scripts/preflight.mjs` — він перевіряє все нижче й друкує ✓/✗.

- [ ] `git status` чистий, `src/app.js` без `function greet`
- [ ] `NTFY_TOPIC` задано і є підписка в застосунку ntfy (див. нижче) — інакше
      демо 4 покаже лише `⚠`
- [ ] Демо 5: застосунок Claude на телефоні, у `~/.claude/settings.json` є
      `"remoteControlAtStartup": true`
- [ ] `claude` запущено **з кореня репо**, довіру до проєктних хуків підтверджено
- [ ] У стартовому виводі є `✓ Node … + усі залежності вже встановлено …`

Порядок показу: **6 → 1 → 2 → 3** (на `main`) → **4 → 5**.
Звук вимикається змінною `DEMO_MUTE=1`.

## Що ви бачите від хуків

Кожен хук завжди друкує один рядок з емодзі (через `systemMessage`, див.
`hooks/lib.mjs`) — навіть коли нічого не зробив («пропущено»). Блокування
(`exit 2`) показується як `PreToolUse:… hook error: …`. Якщо після дії рядка
хука немає — хук не підключено (див. «Якщо щось не спрацювало»).

| Хук                        | Подія              | Звук: macOS / Windows / інше                    |
| -------------------------- | ------------------ | ----------------------------------------------- |
| SessionStart               | старт сесії        | Hero / Exclamation / дзвінок терміналу          |
| protect_env                | до запису файлу    | дозволено — Pop / Asterisk, блок — Basso / Hand |
| block_direct_master_commit | до Bash-команди    | коміт дозволено — Pop, блок — Basso             |
| format_on_write            | після запису файлу | Glass / Asterisk                                |
| notify_pr_created          | після Bash-команди | пуш надіслано — Submarine, ⚠/✗ — Sosumi         |
| notify_mobile              | сповіщення Claude  | Ping (⚠/✗ — Sosumi)                             |

Хуки «пропущено» (команда не та) звуку не мають — лише рядок.

## Кроки демо

1. **Демо 6 — доставка залежностей на старті (SessionStart).** Найлегше
   показати одразу на старті `claude`. Хук перевіряє `git gh`; якщо чогось
   бракує — виводить `⚠ Бракувало: …` і запускає `install.mjs` (Homebrew на
   macOS, winget на Windows, apt на Linux). Коли все на місці — виводить
   `✓ Node … + усі залежності вже встановлено` і нічого не встановлює.

2. **Демо 1 — автоформат (PostToolUse).** Попросіть Claude Code:

   > додай у src/app.js функцію greet(name), яка повертає рядок "Привіт, {name}!"

   Після запису файлу побачите `🎨 ✓ prettier: src/app.js` — файл
   відформатовано автоматично, без нагадувань у CLAUDE.md. Доказ:
   `git diff src/app.js`.

3. **Демо 2 — блокування .env (PreToolUse).** Попросіть Claude Code:

   > відредагуй файл secrets.example: додай рядок API_KEY=demo

   Заблоковано: `protect_env.mjs` поверне exit code 2, і ви побачите
   `🔒 Заблоковано хуком protect_env: правка '…/secrets.example' …`. Для будь-якого
   іншого файлу хук напише `🔒 protect_env: '…' не секретний — правку
дозволено`. Хук ловить шляхи з `.env` або `secrets`. Файл названо
   `secrets.example`, а не `.env.example`, бо загальні правила заборони на
   `.env*` у налаштуваннях користувача спрацьовують раніше за хук. Claude змінює файли інструментами Edit/Write — саме на них
   спрацьовує хук, тож не проситьте «перейменувати» через термінал.

4. **Демо 3 — заборона прямого коміту в master (PreToolUse, безпека).**
   Перебуваючи на гілці `master` або `main` (`git switch main`),
   попросіть:

   > закомить поточні зміни з повідомленням "test"

   `block_direct_master_commit.mjs` реагує на саму команду `git commit`
   (не на будь-який текст із цими словами), перевіряє гілку; якщо це
   `master`/`main` — блокує коміт (exit 2) і виводить
   `🌿 Заблоковано хуком …: прямий коміт у гілку 'main' заборонено`. На іншій
   гілці бачите `🌿 block_direct_master_commit: гілка '…' — коміт дозволено`,
   а для решти Bash-команд — `🌿 … це не git commit — пропущено`.

5. **Демо 4 — сповіщення про створений PR (PostToolUse).** На feature-гілці
   попросіть Claude Code відкрити Pull Request через `gh pr create`. Після
   виконання `notify_pr_created.mjs` пришле push-сповіщення на телефон із
   посиланням на PR і покаже
   `📣 notify_pr_created: ✓ пуш надіслано на ntfy.sh/<топік> — …`. Без
   `NTFY_TOPIC` побачите `📣 ⚠ … NTFY_TOPIC не задано — пуш не надіслано`,
   для інших Bash-команд — `📣 … це не gh pr create — пропущено`.
   Немає свого fork або `gh`? Команда `/demo` покаже безпечну **імітацію**
   (`gh pr create --help`) і чесно позначить її як імітацію.

6. **Демо 5 — сповіщення на телефон (Remote Control).** Коли Claude Code
   потрібна ваша увага (наприклад, запит дозволу на дію), пуш приходить у
   застосунок Claude на телефоні — без жодного хука:

   1. Поставте застосунок **Claude** на телефон (iOS/Android), увійдіть тим
      самим акаунтом, що й у терміналі.
   2. У `~/.claude/settings.json` додайте:
      ```json
      { "remoteControlAtStartup": true }
      ```
      (або тумблер **Enable Remote Control for all sessions** у `/config`)
   3. У `/config` → блок **Notifications** — увімкніть:
      - **Push when actions required** — пуш, коли Claude чекає дозволу
      - **Push when Claude decides** — пуш, коли сам Claude вирішив
        сповістити (задача завершена тощо)

   Показ: попросіть Claude виконати дію, що потребує дозволу, — на телефон
   приходить пуш.

### Налаштування push-сповіщень через ntfy.sh (демо 4)

Сповіщення про PR іде через безкоштовний сервіс [ntfy.sh](https://ntfy.sh).
Задайте топік (будь-який унікальний рядок) **у тому терміналі, звідки
запускаєте `claude`**:

```bash
# macOS / Linux (bash, zsh)
export NTFY_TOPIC="my-claude-code-<унікальний-суфікс>"
```

```powershell
# Windows PowerShell
$env:NTFY_TOPIC = "my-claude-code-<унікальний-суфікс>"
```

Встановіть застосунок **ntfy** на телефон (Android/iOS) і підпишіться на той
самий топік. Без заданого `NTFY_TOPIC` хук нічого не шле, а лише
показує `⚠ … NTFY_TOPIC не задано` (exit 0) — це не ламає інші дії.

## Якщо щось не спрацювало

| Симптом                                                  | Причина                                                                                                                                                                          |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Хуки не запускаються                                     | `claude` запущено не з кореня репо, або не підтверджено довіру до проєктних хуків                                                                                                |
| Помилка `node: command not found` / рядок `NODE_MISSING` | не встановлено Node.js 18+ — Claude запропонує команду для вашої ОС (macOS `brew install node`, Windows `winget install OpenJS.NodeJS.LTS`, Linux `sudo apt install nodejs npm`) |
| Немає `🎨 ✓ prettier`                                    | немає `npx` (входить до Node.js) або немає інтернету при першому запуску prettier                                                                                                |
| Коміт у `main` не блокується                             | поточна гілка не `main`/`master` (`git branch --show-current`)                                                                                                                   |
| Немає пуша                                               | не задано `NTFY_TOPIC` у тому терміналі, звідки запущено `claude`, або немає підписки на топік                                                                                   |
| Немає звуку                                              | `DEMO_MUTE` задано або системний звук вимкнено; на Linux — лише дзвінок терміналу                                                                                                |

Після репетиції верніть `src/app.js` до чистого стану:
`git restore src/app.js` (не `git restore .` — це скасує й інші незакомічені правки).
