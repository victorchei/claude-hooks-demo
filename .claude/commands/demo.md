Проведи користувача через демо хуків цього репозиторію. Українською, простими
словами, коротко. Дотримуйся формату відповіді з `CLAUDE.md` (що зробив →
рядок хука дослівно → що це показує → доказ). Після кожного кроку зупинись і
чекай «далі».

## 0. Перевірка перед стартом

Виконай `node scripts/preflight.mjs` (працює однаково на macOS/Windows/Linux)
і покажи результат списком ✓/✗. Що не так — скажи, як виправити, не виправляй
мовчки. Якщо `node` немає — розділ «Старт сесії: залежності» з `CLAUDE.md`.
`NTFY_TOPIC` для кроків 5–6 потрібен для справжнього пуша; без нього хуки
покажуть `⚠` — це теж валідний показ.

## Кроки

1. **SessionStart (демо 6) — на старті сесії.** Покажи рядок хука зі старту
   (`✓ Node … + усі залежності вже встановлено …`). Якщо його не видно — так і
   скажи: хук міг не підключитися (`claude` запущено не з кореня репо або не
   підтверджено довіру до проєктних хуків).
2. **PostToolUse — автоформат (демо 1) — після запису файлу.** Інструментом
   **Edit** додай у `src/app.js` функцію `greet(name)` «кривим» стилем, щоб
   було що виправляти:
   `function greet( name ){return "Привіт, "+name+"!"}` — перед `main()`.
   Хук prettier має її виправити. Потім `git diff src/app.js` — покажи, що
   змінив хук.
3. **PreToolUse — захист .env (демо 2) — до запису файлу.** Інструментом
   **Edit** (не Bash!) відредагуй наявний зразок `example.env`: додай рядок
   `API_KEY=demo`. Очікуй блокування; після цього перевір, що вміст
   `example.env` не змінився.
4. **PreToolUse — коміт у main (демо 3) — до запуску команди.** Лише якщо
   поточна гілка `main`/`master` (інакше запропонуй `git switch main` і
   дочекайся згоди): виконай `git commit --allow-empty -m "test"`. Очікуй
   блокування; після цього `git log --oneline -1` — історія не змінилась.
5. **PostToolUse — PR (демо 4) — після команди.** Якщо є власний fork/remote і
   `gh auth status` ок — за згодою користувача виконай справжній
   `gh pr create`. Інакше — **імітація**: виконай `gh pr create --help`
   (нічого не створює) і чітко скажи, що це імітація тригера, а не справжній
   PR. Покажи рядок `📣 …` і, якщо задано `NTFY_TOPIC`, що пуш пішов.
6. **Сповіщення на телефон (демо 5) — Remote Control.** Хук тут не потрібен.
   Перевір, що в `~/.claude/settings.json` є `"remoteControlAtStartup": true`
   (сам цей файл не змінюй — попроси користувача). Запроси дію, що вимагає
   дозволу, і попроси показати екран телефона: пуш від застосунку Claude.
   Чи дійшов пуш, ти не бачиш — так і скажи.

## Прибирання

Після кроків запропонуй повернути `src/app.js` (`git restore src/app.js`) і
прибрати `.env`, якщо він з'явився. Не використовуй `git restore .`. Нічого
не пуш і не мерж.
